The first release of Stillread: a calm place to read Markdown on your Mac.

## Reading (free)

- Open a folder and read its notes in a quiet sidebar, set like a page in a typeface made for reading
- Serif or sans, three line widths, any text size, light and dark, and Focus Mode
- GitHub-flavoured Markdown: tables, task lists, footnotes, alerts, Mermaid diagrams and highlighted code
- Pages update as files change on disk, and keep your place
- Quick Look previews in Finder: press Space on any Markdown file
- At home in an Obsidian vault: wikilinks, image embeds, callouts and frontmatter

## Editing (one-time unlock)

- Press **⌘E** to edit a note in place, with Markdown marks softly dimmed
- Saves on its own, writing the file back exactly as it was apart from your changes
- If another app changes the note while you edit, Stillread asks which version to keep
